# Digital Sensing Technologies website

This is a static website for Digital Sensing Technologies, rebuilt from `Website New Proposition v03.docx` and the follow-up investor/validation feedback.

## How to view it

Open `index.html` in a browser. No Node.js, Python, install step, or server is required.

## Files

- `index.html` - page structure and content
- `styles.css` - visual design and responsive layout
- `app.js` - reveal effects, active navigation, and the email form helper
- `DST logo.png` - supplied DST logo
- `DST-logo-mark-only.png` - cropped mark-only logo used by the website
- `breathpass-device.png` - BreathPass device render used as the main proof visual
- `breathpass-mobile.png` - BreathPass mobile app screenshot
- `evidence-epilepsy-pca.png` - epilepsy pilot graph from slide 13 of the IM deck
- `evidence-forensic-pca.png` and `evidence-forensic-roc.png` - forensic pilot graphs from slide 15 of the IM deck
- `logo-*.png` - collaboration logos from slide 7 of the IM deck
- `team-*.png` - team portraits used in the team section
- `LadyBreathingVOCs1.png` - breath/VOC visual used in the Why breath section
