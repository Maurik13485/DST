# Digital Sensing Technologies website

This is a static website starter for Digital Sensing Technologies, rebuilt from `Website New Proposition v03.docx`.

## How to view it

Open `index.html` in a browser. No Node.js, Python, install step, or server is required.

## Files

- `index.html` - page structure and content
- `styles.css` - visual design and responsive layout
- `app.js` - reveal effects, active navigation, and the email form helper
- `DST logo.png` - supplied DST logo
- `DST-logo-mark-only.png` - cropped mark-only logo used by the website
- `LadyBreathingVOCs1.png` - supplied breath/VOC hero visual

## Notes for the next editing round

The site is intentionally static so it can be shared as a folder or ZIP and opened directly in a browser.
